# লালি কোথায়? — ২D কার্টুন (Remotion প্রজেক্ট)

তোমার দেওয়া **ভয়েস (২টা MP3) + SRT + ক্যারেক্টার ছবির জিপ** দিয়ে বানানো পুরো ২D অ্যানিমেশন।
কোড আকারে দেওয়া হলো — তুমি নিজের কম্পিউটারে রেন্ডার করে MP4 পাবে।

* দৈর্ঘ্য: ~৪ মিনিট ২৭ সেকেন্ড (৮০১৭ ফ্রেম, 30fps), 1920×1080 (YouTube 16:9)
* ভয়েস, সাবটাইটেল, ঠোঁট নাড়া (lip-sync) — সব ভয়েসের সাথে মিলিয়ে টাইম করা
* সাউন্ড ইফেক্ট (বজ্রপাত, বৃষ্টি, ব্যাঙের লাফ, কাদার ছপাৎ...) আর ব্যাকগ্রাউন্ড মিউজিক যোগ করা আছে

---

## রেন্ডার করার নিয়ম (একবারই সেটআপ)

1. **Node.js 18 বা নতুন** ইনস্টল করো → https://nodejs.org
2. জিপ খুলে ফোল্ডারে টার্মিনাল/কমান্ড প্রম্পট খোলো
3. চালাও:

```bash
npm install
```

```bash
npm run render
```

ভিডিও তৈরি হবে: `out/lali-kothay-full.mp4`
(প্রথমবার Remotion নিজে একটা Chrome ডাউনলোড করবে — ইন্টারনেট লাগবে।)

### আরো অপশন

| কমান্ড | কী হবে |
|---|---|
| `npm run render` | পুরো এপিসোড (ভয়েস+সাবটাইটেল+মিউজিক) |
| `npm run render:part1` | শুধু পর্ব-১ অংশ (লালি কাদা থেকে উঠা পর্যন্ত) |
| `npm run render:part2` | শুধু শেষ অংশ (মাফ চাওয়া → পিঠা → Subscribe) |
| `npm run render:nosubs` | সাবটাইটেল ছাড়া |
| `npm run render:original-voice` | ElevenLabs এর আসল ভয়েস (ক্যারেক্টার ভয়েস চেঞ্জ ছাড়া) |
| `npm run render:preview` | দ্রুত ছোট (540p) প্রিভিউ |
| `npm run thumbnail` | YouTube থাম্বনেইল `out/thumbnail.png` |
| `npm start` | ব্রাউজারে Remotion Studio — টাইমলাইন দেখে দেখে চেক/এডিট |

কম্পিউটার স্লো হলে: `npx remotion render LaliEpisode out/video.mp4 --concurrency=2`

## ক্যারেক্টার ও তাদের ফিক্সড ভয়েস

প্রতিটা ক্যারেক্টার **পুরো গল্পে একই চেহারা আর একই গলায়** থাকে।
দুইটা ভয়েস ফাইল দুই আলাদা ভয়েসে (Rimjhim = মেয়ে, Huzaifa = ছেলে) ছিল, তাই প্রতিটা লাইন কেটে
ক্যারেক্টারের নির্দিষ্ট পিচ ও গলার সাইজে নেওয়া হয়েছে (Praat PSOLA) — টাইমিং একটুও বদলায়নি।

| ক্যারেক্টার | ছবি (তোমার জিপ থেকে) | ভয়েস |
|---|---|---|
| কালাম চাচা | ধূসর দাড়ি, পাঞ্জাবি | বয়স্ক পুরুষ, ভারী গলা (~118 Hz) + হালকা কাঁপুনি |
| সুমন ভাই (পুলিশ) | টুপিওয়ালা লোক → নীল ইউনিফর্ম + পুলিশ ক্যাপ বানানো হয়েছে | পুরুষ (~130 Hz) |
| তানিম | বাদামি গায়ের রঙের ছেলে, ভেস্ট | ছেলে শিশু (~265 Hz) |
| আয়েশা | লাল কামিজ, সবুজ সালোয়ার | মেয়ে শিশু (~305 Hz) |
| নানু | চশমা পরা দাদি/নানি, শাড়ি | বয়স্ক মহিলা + কাঁপুনি |
| লালি (গরু) | লালচে-বাদামি গরু | মোটা গরু-গলা "হাম্বা" |
| ভোলা (কুকুর) | জিপে ছিল না → একই স্টাইলে আঁকা | মজার কুকুর গলা |
| কুক্কু (মুরগি) | জিপে ছিল না → আঁকা | চিকন কুঁক-কুঁক গলা |
| মিনি (বিড়াল) | জিপে ছিল না → আঁকা | ছোট্ট মিউ-গলা |
| গল্পকথক | — | পর্ব-১ এর আসল নারী কণ্ঠ |

ব্যাকগ্রাউন্ড: জিপের গ্রাম/নদী/বটগাছের ছবি + কোডে আঁকা গোয়ালঘর, কুঁড়েঘর, খড়ের গাদা, বেড়া, কাদা, দড়ি, গামছা, পিঠা।

### ভাইরাল-স্টাইল যা যা রাখা হয়েছে
* প্রথম ৩ সেকেন্ডে হুক: কালাম চাচার কান্না "আমার লালি নেই!" → বজ্রপাতে টাইটেল
* প্রতি ২-৫ সেকেন্ডে শট/ক্যামেরা বদল, যে কথা বলছে ক্যামেরা তার দিকে জুম করে
* কারাওকে সাবটাইটেল (যে শব্দ বলা হচ্ছে সেটা হলুদ হয়ে লাফায়) + বক্তার নামের ট্যাগ
* চোখের পলক, মুখ নাড়া, মাথা দোলানো, কান্নার পানি, রাগে লাল মুখ, 💡❗❓❤️ রিঅ্যাকশন
* বৃষ্টি-বজ্রপাত, রংধনু, জোনাকি, কনফেটি, বড় বড় পপ-লেখা (১-২-৩, হেইয়ো!, ঘ্যাঁচ!)
* "গল্পের শিক্ষা" ব্যানার, শেষে লাইক/শেয়ার/Subscribe অ্যানিমেশন + পরের পর্বের টিজার

## কিছু বদলাতে চাইলে

* **ভয়েস বদলালে / নতুন MP3 দিলে:** `tools/voice/source/` এ রাখো, `tools/voice/script_lines.py` এ লাইন-কে-কে বলছে ঠিক করো, তারপর
  ```bash
  pip install praat-parselmouth numpy
  ```
  ```bash
  python tools/voice/align.py tools/voice tools/voice/source tools/voice/lines.json
  ```
  ```bash
  python tools/voice/process_voices.py
  ```
  ```bash
  python tools/audio/make_sfx_music.py
  ```
  (ffmpeg লাগবে।) সিন কাটগুলো লাইনের সময়ের সাথে বাঁধা, তাই সব নিজে থেকে মিলে যাবে।
* **কোন ক্যারেক্টারের গলা কেমন হবে:** `tools/voice/process_voices.py` এর `VOICES` (median = পিচ, tract = গলার সাইজ)
* **সিন/অ্যাকশন:** `src/scenes/*.tsx` (প্রতিটা সিনের উপরে কমেন্টে লেখা কোন লাইন)
* **ক্যারেক্টারের সাইজ/রং/নাম:** `src/characters/rigs.ts`
* **সাবটাইটেলের ফন্ট/রং:** `src/ui/Subtitles.tsx`
