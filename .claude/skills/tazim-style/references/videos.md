# Tazim: বিশ্লেষণ করা ভিডিও

প্রতিটা নতুন ভিডিও এখানে একই ছাঁচে যোগ হবে। এখানে শুধু বিশ্লেষণ রাখা হয়, ভিডিও ফাইল রিপোতে রাখা হয় না।
